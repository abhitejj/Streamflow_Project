# Weather input inventory and provenance limits

Inventory recorded 16 November 2026 from the local CSVs and `scripts/download_era5_land.py`. CSV structure and hashes are verified; provider and model identity are inferred from the downloader request, not confirmed by response metadata or an independent provider audit.

The downloader calls the Open-Meteo Historical Weather API at `archive-api.open-meteo.com/v1/archive` for station-catalog coordinates joined by exact CAMELS gauge ID and rounded to four decimal places, dates 2001-01-01 through 2025-12-31, daily mean/max/min 2 m temperature and `et0_fao_evapotranspiration`, timezone GMT. The JSON manifest records these reconstructed request coordinates; they are not recovered from HTTP request logs. The script does **not** send a `models` parameter. Thus the request uses the API's default Best Match selection, not an explicitly selected ERA5-Land series. Best Match can select/combine products according to availability; a filename containing `era5_land` does not establish that every row or variable came from ERA5-Land. The PET column is FAO reference evapotranspiration (`et0_fao_evapotranspiration`), not GLEAM potential evapotranspiration.

See the [official Historical Weather API documentation](https://open-meteo.com/en/docs/historical-weather-api), especially its model selection guidance. The request URL contains timezone GMT, but the CSV alone cannot establish the provider's precise daily accumulation boundary or operational publication delay. Do not claim Monday 00:00 UTC real-time availability from this inventory.

All 12 candidate files have 9,131 rows, dates 2001-01-01 through 2025-12-31 inclusive, columns `Date,tavg_c,tmax_c,tmin_c,pet_mm`, no missing cells, no duplicate dates, and finite numeric values. These checks establish usable file shape, not data-source correctness or a homogeneous model product.

The recreated Karnataka CWC archive contains 34,007 rows across Yadgir (8,949), Huvinhedigi (8,961), KUDIGE (8,341), and Haralahalli (7,756). Station, state, original acquisition-time, and discharge fields are present. Its whole-file SHA256 is recorded in the JSON manifest. The archive's lineage is not proven by matching the processed merged file's whole-file hash; it remains a supplied source file with original archive provenance to be confirmed.

Use these supplied inputs only under the user's explicit instruction to use them as provided. Record their hashes and source qualification with every derived tensor. Do not relabel the weather as pure ERA5-Land or infer source uniformity from the CSVs. Existing numeric model results are not evidence that these newly inventoried files generated the old tensors.
